Configuration requise

Cette version est prête pour une base Supabase partagée. Renseigne les deux valeurs publiques dans config.js, puis mets le site en ligne.

  1. Créer le projet Supabase.
  2. Exécuter supabase_schema.sql.
  3. Copier l’URL du projet et la clé publique dans config.js.
  4. Déployer ce dossier sur un hébergeur web.

N’ajoute jamais une clé secret/service_role dans ce site.
