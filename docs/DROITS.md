# Qui peut faire quoi

**En clair** : les rôles techniques restent les 4 existants. Les droits d'organisation (Phase 2) viennent des **tâches confiées**, pas d'un nouveau rôle : un graphiste ou un vidéaste est un « Responsable plateforme » **sans plateforme**, avec son intitulé de poste ; il fait avancer ce qu'on lui confie. Tout est appliqué par la base.

Légende : **L** lire · **C** créer · **M** modifier · **—** aucun accès.

Règles permanentes :
- Le **pays** est descriptif : il ne restreint ni n'élargit aucun accès. L'**intitulé de poste** est descriptif.
- Personne ne modifie son propre rôle ; la base refuse de laisser l'équipe sans administrateur actif.
- Aucun profil n'est supprimé (désactivation, retrait) ; un identifiant n'est jamais réattribué.
- Compte inactif, retiré, ou mot de passe à changer : aucune donnée métier. À partir de la 08P : session d'avant le lundi 00:00 (Lomé) refusée.
